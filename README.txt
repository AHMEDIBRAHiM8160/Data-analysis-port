AHMED IBRAHIM — PORTFOLIO FRONT-END

Files:
- index.html
- style.css
- script.js
- assets/profile-placeholder.svg

HOW TO CUSTOMISE
1. Replace assets/profile-placeholder.svg with your own portrait photo.
   Save your photo as assets/profile.jpg, then change both image paths in index.html
   from assets/profile-placeholder.svg to assets/profile.jpg.
2. Replace social media href="#" values with your actual Facebook, YouTube and LinkedIn URLs.
   Replace https://wa.me/ with your WhatsApp link in international format, e.g. https://wa.me/234XXXXXXXXXX.
3. Replace each project href="#" with the live website, GitHub repository or demo link.
4. Add your CV PDF as assets/Ahmed-Ibrahim-CV.pdf. The Download CV button already points there.
5. Replace your-email@example.com with your real email address.
6. Update project descriptions/tools to reflect the exact work you completed.

RUN LOCALLY
Open index.html in a browser, or open the folder in VS Code and use Live Server.
No backend, framework, database or build step is required. This is plain HTML, CSS and JavaScript.

WELCOME SCREEN
The welcome screen appears on page load and fades away after about 2.7 seconds.

CONTACT SECTION
- Replace +2340000000000 and +234 XXX XXX XXXX with your real phone number.
- Replace your-email@example.com with your professional email.
- Add your LinkedIn URL to the contact card.
- Social icons are inline SVG marks; replace the # href values with your own profile URLs.
